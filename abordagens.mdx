# **Código 2 (suspeita):**

Na abordagem de código 2 o cidadão pode sair do local de uma denúncia (exemplo: Venda de Droga), porém não tivemos de fato o visual do mesmo executando a ação. O diálogo deve ser priorizado, afinal você o considera suspeito e não uma situação de flagrante.

# **Código 3 (flagrante):**

Na abordagem de código 3 o indivíduo é pego no ato, flagrante entregando drogas entre outros possíveis crimes.
