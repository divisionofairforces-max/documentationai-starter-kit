---
title: Código de patrulha
---
São utilizados na modulação para descrever a gravidade das ocorrências:

| **Código** | **Significado**                |
| :--------- | :----------------------------- |
| 0          | Em patrulha (início/retorno)   |
| 1          | Abordagem de baixa intensidade |
| 2          | Abordagem de média intensidade |
| 3          | Abordagem de alta intensidade  |
| 4          | Situação sob controle          |
| 5          | Fogo aberto (alerta máximo)    |
| 6          | Busca no perímetro             |
