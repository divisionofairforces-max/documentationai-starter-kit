---
title: Código Q
---
A utilização do “Código Q” durante a patrulha visa otimizar o tempo de modulação e garantir que a mensagem seja entregue de forma clara e objetiva para quem está escutando.

Para identificação de situações de risco, são utilizados números conforme a tabela a seguir.

| **Código** | **Significado**                                                                                                             |
| :--------- | :-------------------------------------------------------------------------------------------------------------------------- |
| QAP        | Na escuta. Exemplo: "QAP Fulano"                                                                                            |
| QSA        | Teste de frequência. Exemplo: "QSA, central?" A itensidade do sinal varia de 1-5, sendo 1 inaudível e 5 completamente claro |
| QRR        | Apoio/Reforço. Exemplo: "QAP Central, solicito QRR"                                                                         |
| QSV/VTR    | Viatura. Exemplo: "Alguma QSV/VTR com vaga?"                                                                                |
| QRL        | Ocupado. Exemplo: "400M QRL - Mecânica"                                                                                     |
| TKS        | Obrigado. Exemplo: "TKS pelo informe"                                                                                       |
| QRU        | Ocorrência. Exemplo: "Central, alguma QRU em andamento?"                                                                    |
| QTX        | Saindo de serviço. Exemplo: "400M QTX"                                                                                      |
| QRV        | As suas ordens. Exemplo: "400M QRV"                                                                                         |
| QRX        | Cessar comunicação. Exemplo: "QRX, Central"                                                                                 |
| QSJ        | Dinheiro. Exemplo: "200K de QSJ"                                                                                            |
| QRA        | Identificação. Exemplo: "Qual o seu QRA?"                                                                                   |
| QTC        | Mensagem. Exemplo: "Central, qual a última QTC?"                                                                            |
| QTO        | Sanitário. Exemplo: "400M QTO"                                                                                              |
| QTA        | Cancelar informe. Exemplo: "Pode dar QTA do oficial ferido, central"                                                        |
| QTI        | À caminho. Exemplo: "QTI da último do Cód.5"                                                                                |
| QSM        | Repetir informação. Exemplo: "QSM na última QTC"                                                                            |
| QTH        | Localização. Exemplo: "Fulano, qual o seu QTH?"                                                                             |
| QSL        | Entendido. Exemplo: "Pode dar QTA do oficial ferido, central" "QSL"                                                         |
| PTR        | Patrulha. Exemplo: "Central, formação no departamento para dividir PTR"                                                     |
